# ①課題名
スラムダンク検定アプリ

## ②課題内容（どんな作品か）
- Firebaseを利用した、チャット風クイズアプリ
- スラムダンクに関するクイズに答えて点数を記録する

## ③アプリのデプロイURL
デプロイしている場合はURLを記入（任意）

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 今回はなし
- PW: 今回はなし

## ⑤工夫した点・こだわった点
- これまでに習得した機能をできるだけ盛り込むようにしました。
- クイズ事前登録100問の中から5問を抽出する際、ランダムなるように、Math Randomを利用。
- 前回スコアと最高スコアを保持するためにLocal  Strageを利用。
- FirebaseのAPIなどの秘匿情報はGitIgnoreファイルに記載しGitHubの管理対象外に設定。
- クイズの回答と判定で間を開けて、ドキドキ感が出るように調整。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 最初の設定の手順（サイトからAPIなどをコピーしてくるところ）に慣れるまで時間がかかりそうです。また、APIキーを一度GitHubに上げてしまって、リポジトリを削除することになったので、こうした動作は当たり前にできるようにしておきたいです。次回はいろんなAPIを使って、より複雑なアプリを作りたいです。
